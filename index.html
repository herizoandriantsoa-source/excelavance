Leçon : Excel Avancé (Base de données, Consolidation et TCD)

Base de données, consolidation et tableaux croisés dynamiques. Ce module permet de trier des bases de données complexes, de lier plusieurs feuilles de calcul et de synthétiser des milliers de lignes de données grâce aux Tableaux Croisés Dynamiques (TCD).

1. Base et gestion des données2. Mise en forme conditionnelle3. Consolidation4. TCD

1Base et gestion des données

Les outils indispensables pour organiser, filtrer et nettoyer de grands tableaux avant de les analyser.

Tri personnalisé

Description : ordonne un tableau selon plusieurs critères successifs (imbriqués) plutôt qu’un seul.

Chemin : Accueil › groupe Trier › Tri personnalisé…

Exemple : tableau de ventes avec les colonnes Dates, Magasins et CA. Classement :
  • par Dates (du plus ancien au plus récent) ;
  • puis par Magasins (de A à Z) ;
  • enfin par CA (du plus petit au plus grand).

Filtre avancé

Description : extrait des lignes précises vers un nouvel emplacement, grâce à des critères écrits dans une zone séparée.

Chemin : Données › groupe Trier et filtrer › Avancé

Exemple : tableau principal en A1:C100 ; zone de critères en E3:E4 (en-tête « Magasins » et valeur « Paris » dessous).
  • Plages : A1:C100
  • Zone de critères : E3:E4
  • Copier dans : E7:F7

Résultat : seules les lignes des magasins de Paris sont copiées dans la nouvelle zone.

Sous-totaux automatiques

Description : calcule des lignes de totaux partiels (somme, moyenne…) à chaque changement de valeur dans une colonne.

Règle d’or : il faut obligatoirement trier la colonne cible avant de lancer l’outil.

Chemin : Données › groupe Plan › Sous-total

Exemple : après avoir trié « Magasins » : À chaque changement de : Magasins ; Fonction : Somme ; Ajouter un sous-total à : CA.

Résultat : des lignes Total Cannes, Total Lyon… et un Total général en bas.

Figer les volets

Description : bloque les premières lignes ou colonnes à l’écran pour qu’elles restent visibles quand on fait défiler un long tableau.

Chemin : Affichage › groupe Fenêtre › Figer les volets

Liste déroulante (Validation des données)

Description : restreint la saisie d’une cellule à un choix dans une liste prédéfinie.

Chemin : Données › groupe Outils de données › Validation des données

Exemple : cellule F4 limitée à certains codes. Autoriser : Liste ; Source : la plage des codes (ex. A1:A5 contenant CDM1, VAL1, ARD1…). Une flèche apparaît sur la cellule.

Supprimer les doublons

Description : efface définitivement les lignes identiques pour ne garder que des données uniques.

Chemin :
1. Données › groupe Outils de données › Supprimer les doublons
2. Ctrl+L › Création › Supprimer les doublons

Segment (Slicer)

Description : petit encadré avec un bouton par valeur unique d’une colonne (ex. un bouton par magasin). Il filtre un tableau ou un TCD en un clic, sans ouvrir les menus de filtre, et on voit tout de suite quel critère est actif.

Chemin : convertir d’abord les données en Tableau (Ctrl+L), puis Insertion › groupe Filtres › Segment…

2Mise en forme conditionnelle

Applique automatiquement une mise en forme (couleur de fond, de police, barres, icônes) selon la valeur des cellules. Si la valeur change, la mise en forme s’adapte seule. Idéal pour repérer d’un coup d’œil les valeurs importantes, anormales ou en double.

Chemin général : Accueil › groupe Style › Mise en forme conditionnelle

Règles de mise en surbrillance des cellules

Description : colore les cellules qui répondent à une condition simple : supérieur à, inférieur à, entre, égal à, texte contenant, date, valeurs en double.

Exemple : colonne CA (C2:C100) › Inférieur à… › 1000 › « Remplissage rouge clair avec texte rouge foncé ».

Résultat : tous les CA inférieurs à 1000 s’affichent en rouge ; si on corrige un chiffre, la couleur disparaît automatiquement.

Variante utile : Valeurs en double permet de repérer les doublons avant de les supprimer.

Règles de valeurs plus/moins élevées

Description : met en évidence les N premières ou dernières valeurs, un pourcentage, ou les valeurs au-dessus/en dessous de la moyenne.

Exemple : colonne CA › 10 valeurs les plus élevées… › 10 avec remplissage vert.

Résultat : les 10 meilleures ventes sont en vert. Avec Au-dessus de la moyenne, tous les CA dépassant la moyenne de la colonne sont colorés.

Barres de données

Description : insère dans chaque cellule une barre horizontale proportionnelle à sa valeur.

Exemple : sélectionner C2:C100 et choisir une barre de données bleue.

Résultat : on compare les magasins sans lire les chiffres, comme un mini-graphique dans les cellules.

Nuances de couleurs

Description : applique un dégradé de 2 ou 3 couleurs selon la valeur (ex. rouge pour les plus petites, vert pour les plus grandes).

Exemple : tableau de CA par mois et par magasin › Vert - Jaune - Rouge.

Résultat : une carte de chaleur qui montre les bonnes et mauvaises périodes.

Jeux d’icônes

Description : ajoute une icône (flèche, feu tricolore, étoile…) selon la tranche où se situe la valeur.

Exemple : jeu 3 feux tricolores sur la colonne CA.

Résultat : un feu vert, orange ou rouge selon le niveau de CA. Pour régler les seuils : Mise en forme conditionnelle › Gérer les règles › Modifier la règle.

Nouvelle règle avec formule (cas avancé)

Description : permet de mettre en forme toute la ligne ou d’appliquer une condition personnalisée avec une formule qui renvoie VRAI ou FAUX.

Chemin : Mise en forme conditionnelle › Nouvelle règle… › Utiliser une formule pour déterminer les cellules pour lesquelles le format sera appliqué

Exemple : colorer toute la ligne du magasin Paris : sélectionner A2:C100, saisir =$B2="Paris" (B = colonne Magasins), choisir une couleur de remplissage.

Résultat : les lignes entières des ventes de Paris sont colorées.

Règle d’or : le $ devant la lettre de colonne ($B2) fixe la colonne ; pas de $ devant le numéro de ligne pour que la formule s’adapte à chaque ligne. La formule s’écrit toujours en pensant à la première cellule de la plage sélectionnée.

Gérer et effacer les règles

Description : modifier, supprimer, hiérarchiser les règles existantes ou les effacer.

  • Mise en forme conditionnelle › Gérer les règles… (modifier, supprimer, changer l’ordre de priorité)
  • Mise en forme conditionnelle › Effacer les règles › de la feuille entière (ou de la sélection)
Exemple : si deux règles se contredisent, celle placée en haut de la liste l’emporte. On peut la déplacer avec les flèches.

Remarque : format de nombre personnalisé (conditions et couleurs)

Description : définit comment une valeur s’affiche (couleur, signe, décimales, texte) selon des conditions, sans formule et sans modifier la valeur réelle.

Chemin : sélectionner les cellules › Ctrl+1 (ou clic droit › Format de cellule) › onglet Nombre › Catégorie Personnalisée › saisir le code dans la zone Type

Structure : Section1;Section2;Section3;Section4

  • Sans condition : positif ; négatif ; zéro ; texte.
  • Avec conditions : deux au maximum entre crochets (ex. [>5]). La section suivante gère tous les autres cas.
Exemple : [vert][>5]0;[rouge][<5]-0;[noir]0 affiche en vert ce qui dépasse 5, en rouge ce qui est inférieur à 5 et en noir le reste.

Remarque : les noms de couleurs dépendent de la langue d’Excel : [Vert], [Rouge], [Noir], [Bleu]… en version française ; [Green], [Red]… en version anglaise.

3Calculs multi-feuilles et consolidation

Comment additionner ou fusionner des informations éparpillées sur plusieurs feuilles de calcul.

Somme dans plusieurs feuilles (Somme 3D)

Description : additionne la même cellule ou la même plage à travers un bloc de feuilles successives.

Syntaxe standard : =SOMME(Première_Feuille:Dernière_Feuille!Cellule)

Exemple 1 : =SOMME(feuil1:feuil3!C2) additionne la cellule C2 des Feuilles 1, 2 et 3.

Syntaxe dynamique (INDIRECT) : =SOMME(INDIRECT(Cellule_Nom_Feuille&"!Plage"))

Exemple 2 : si B6 contient le nom exact d’une feuille, =SOMME(INDIRECT(B6&"!B3:B5")) additionne la plage B3:B5 de cette feuille.

Consolidation de tableaux

Description : fusionne les données numériques de plusieurs tableaux de même structure (feuilles JANV, FEV, MAR) en un seul tableau récapitulatif.

Chemin : Données › groupe Outils de données › Consolider

Exemple : ventes de pièces (Roues, Vélos, Pneus) par employé (Robert, Josette, Pierre) sur JANV, FEV et MAR. Dans Consolider, ajouter chaque référence (ex. JANV!$B$3:$E$7) et cocher Ligne du haut et Colonne de gauche.

Résultat : un tableau unifié avec la somme automatique pour chaque employé.

4Les Tableaux Croisés Dynamiques (TCD)

Un TCD permet de croiser, filtrer et résumer des données brutes sans écrire aucune formule.

Insertion d’un TCD de base

Chemin : Insertion › Tableau croisé dynamique

Exemple : sélectionner Ventes!$A$1:$C$100 (Dates, Magasins, CA) et le placer sur une Nouvelle feuille de calcul.

Le volet des champs – glisser les en-têtes dans les 4 zones :

  • Filtres : filtre tout le tableau (ex. champ Mois)
  • Colonnes : en-têtes horizontaux (ex. champ Dates)
  • Lignes : lignes verticales (ex. champ Magasins)
  • Valeurs : éléments chiffrés à calculer (ex. CA devient « Somme de CA »)

Mettre à jour un TCD et modifier la source

Mise à jour directe : un TCD ne se recalcule pas en temps réel si l’on modifie le tableau d’origine ; il faut forcer l’actualisation.

Action : clic droit dans le TCD › Actualiser (ou onglet Analyse du TCD › Actualiser)

Modifier la source de données : utile quand on ajoute de nouvelles lignes ou colonnes au bout du tableau d’origine.

Action : sélectionner le TCD › onglet Analyse du tableau croisé dynamique › Changer la source de données › redéfinir la plage (ex. passer de E4 à E5)

Segments et chronologies

Segment (Slicer) : boutons graphiques flottants pour filtrer le TCD en un clic.

Exemple : segment sur le champ Service → boutons « Achats », « Commercial », « Comptabilité ». Cliquer sur « Achats » masque tout le reste.

Chronologie : segment spécialisé pour les dates (années, mois) sous forme de frise interactive.

Exemple : glisser le curseur sur l’année 2012 ou sur JUIL pour isoler le chiffre d’affaires de cette période.

Paramètres d’affichage avancés

Modifier la disposition : change le style de présentation du TCD.

Action : Création › Disposition du rapport (compacte, plan, ou tabulaire, avec ou sans répétition des étiquettes)

Afficher les valeurs en pourcentage : transforme les nombres bruts en indicateurs de performance.

Action : clic droit sur une valeur › Paramètres des champs de valeurs › Afficher les valeurs › choisir « % du total général » ou « % du total de la colonne »

Résultat : au lieu de 199 674,25 €, Excel affiche directement 1,26 % de contribution au chiffre d’affaires global.
